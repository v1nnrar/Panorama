# Panorama Hotel — project instructions

Architectural plan for the Panorama Hotel: first a faithful model of the client's **existing scheme**
(rebuilt from their renders), then our **proposed** new building.

## Stack
- **Blender 5.2 (`bpy`)** for scene, materials, renders (Cycles CPU / Workbench), `.blend` and `.glb`
- **IfcOpenShell 0.9** for the BIM model (IFC4); opens in Blender with the **Bonsai** add-on on desktop
- **Shapely** for site geometry, **ezdxf** for DXF drawings, **pandas** for XLSX schedules
- Environment: `./setup.sh` (creates `.venv`). Always run Python as `.venv/bin/python`.

## Single source of truth
Each scheme is ONE parameters YAML. Every output is generated from it — never hand-edit generated files.

```
params YAML ──► pipeline/build_ifc.py ──► model.ifc
                                    └──► pipeline/blender_scene.py ──► model.blend, model.glb, render_*.png
            └──► pipeline/analysis.py ──► report.md, metrics.json, area_schedule.xlsx, drawings/*.dxf|png
```

Build: `.venv/bin/python build.py <params.yaml> [--render] [--engine WORKBENCH] [--rules <rules.yaml>]`
Use `--engine WORKBENCH` for fast clay checks (needs Mesa EGL: `apt-get install -y libegl1 libgl1-mesa-dri`); Cycles (~30 s/camera) for presentation.
Schemes use `buildings:` (list) and `site: {file: ../00_site/site.yaml}`.

## Params schema (per building)
```yaml
- id: B                       # short id, prefixes storey names
  footprint: [[x,y], ...]     # outer face of the facade, any orientation (made CCW)
  height: 68.9                # optional: repeated storeys are scaled so the parapet top hits it
  ground_elevation: -7.0      # optional, basements
  storeys: [{name, height, count, use, windows: {...}|false}]
  windows: {width, height, sill, spacing, edge_margin}   # punched windows in solid walls
  material: Render white      # wall material (IfcMaterial name → Blender PALETTE)
  setbacks:                   # per-storey footprint changes (terraces, overhangs)
    - {facing: [S, E], per_storey: 1.0, from: 2}     # cumulative step back
    - {facing: W, distance: -4.0, from: 1, to: 6}    # fixed (negative = outward)
  terrace_edge: {planter: true, railing: true}       # on slab edges exposed by setbacks
  facade:                     # rules apply to storeys from..to (1-based, inclusive), facing = compass list
                              # or near: [[x,y], ...] = the single edge whose midpoint is closest (recesses)
    - {type: curtain, glass: Glass, mullion: 1.5, spandrel: 1.0}   # replaces walls + windows
    - {type: balcony, depth: 1.6, planter: true, railing: true}
    - {type: band, depth: 0.5, thickness: 0.4, every: 2}           # slab-edge band
    - {type: fins, spacing: 1.2, width: 0.1, depth: 0.4, offset: 0, material: Timber}
    - {type: diagrid, offset: 1.9, bays: 5, storeys_per_module: 3, member: [w, d], above_roof: 1.1}
  roof:
    parapet: 1.1
    slab: true
    green: true
    structures: [{name, dx, dy, w, d, h, green, material}]  # local frame: centroid + longest edge
    pv: {azimuth: building|deg, tilt, row, gap, exclude_center: [w, d]}
    sawtooth: {azimuth, tilt, row, gap}
```
Scheme level: `landscape: {paths, lawns, courtyard_trees, context_tree_radius}`, `render: {cameras, sun_*, samples}`.
A camera may list `hide: [C1, C2]` = buildings the client render it reproduces leaves out (hidden for that camera only).
Site (`00_site/site.yaml`): parcels, `context_glb` (PSG surroundings), `context_exclude`, `trees`.

## Conventions
- Units: metres. Local survey frame (00_site/survey/README.md): aeqd at Milevská 7, x = east, y = true north, z = 0 at GF. Grid axes: columns A… from x=−150, rows 1… from y=+200 (D5 = origin).
- Plot = official ČÚZK parcels (WFS), 16,487 m². Convert to S-JTSK (EPSG:5514) with tools/site_survey.py helpers.
- Footprints are polygons; the pipeline makes them CCW. Footprint = outer face of the exterior wall.
- Every number taken from a document records its source (file + page/article) in a YAML comment.
  Every **assumed** number is marked `# ASSUMED: <reason>` so it can be replaced later.
- Rules in `rules.yaml` use metrics from `pipeline/analysis.py::metrics` (`height_top_of_parapet_m`,
  `storeys_above_ground`, `built_up_ratio`, `plot_ratio_far`, `min_setback_m`, `gfa_m2`, …).
  If a rule needs a new metric, add it to `metrics()` first.

## Regulation checks
`pipeline/psp.py` adds to every build: PSP §21 distance angle (neighbour windows), §22 boundary distance, §25 parking
(need vs basement capacity, zone 02 ASSUMED), hotel keys / flats estimates, own-façade daylight proxy, courtyard sun
(21 March). Limits live in `02_regulations/rules.yaml` (MPP + PSP, each with its source; see `02_regulations/summary.md`).
Mark kept existing buildings with `existing: true`. Options are ranked by `tools/score_options.py`.

| drawings-producer | `05_drawings/` | changes the model |
| compliance-checker | `06_reports/compliance_*.md` | changes the model or rules |
| visualizer | renders, web viewer, presentation images | changes geometry |
| design-reviewer | `06_reports/review_*.md` | changes files outside reports |

Only **bim-modeler** changes geometry. Run **compliance-checker** after every model change.
